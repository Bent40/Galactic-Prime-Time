# Project Brief

## Purpose

Item Drafting content pass: stock the GPT loot-box economy (box tiers, item
pools, tier ladders for all categories) so the campaign can leave the tutorial.

## Scope

Passover doc + owner sitting; item authoring batches A-D; seed script; small
rules slivers (armor numbers, Exceptional path); book pass; optional minimal
ItemTemplate metadata.

## Out of scope

Player-facing draft/pick UI (possible follow-on); F4-6 floor content; any
change to player-held item instances.

## Stakeholders

Owner/GM (rules authority, sole approver of rulings); the four players
(consumers of the item catalog).

## Constraints

Canonical rules master is rulebook/gpt-system-v1.0.md; campaign DB touched only
via backup -> dry-run -> --apply runbook; commit everything (ephemeral
container); no PRs unless asked.
